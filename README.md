# Qixton 3D Website

Static HTML/CSS/JS website designed for free hosting on GitHub Pages.

## Run locally
Open `index.html` in a browser. For the 3D orb and scroll animations, internet access is required because Three.js and GSAP are loaded from a CDN.

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Go to Settings → Pages.
4. Under Build and deployment, choose "Deploy from a branch".
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub to publish the site.
7. Add your custom domain in Settings → Pages → Custom domain.

## Before launch
Replace placeholder portfolio names, stats, email address, and copy with your real business information.
